# TargetBridge 3.6.1 (Unreleased)

This maintenance candidate follows 3.6.0. It is not a published release yet.

## Changes

- Improve Simplified Chinese wording in Sender and Receiver (#212).
- Follow the supported macOS language order on first launch, while preserving
  an explicitly saved language; fall back to English if necessary (#213).
- Centre the Receiver connecting-screen text and translate its role label in
  all five supported languages (#214).
- Correct the Receiver waiting-screen layout orientation (#215), and scale
  the idle dashboard to keep cards and help text separate in smaller windows.
- Exclude development-only scripts from the Sender app bundle while keeping
  language and addon resources (#216).
- Keep Sender and Receiver version stamps aligned, with regression coverage
  for the Sender's footer and bundle version.

## Validation And Remaining Checks

The candidate is being checked with Sender unit tests, portable Receiver
tests, five-language resource validation, and a local mock-sender smoke test.
The small-window layout also has portable geometry regression coverage.

Before publication, validate the final packaged apps on both supported
architectures and run a real two-Mac Thunderbolt session covering video,
audio relay, input roles, native cursor shapes, reconnect and display scaling.
Local loopback tests are not a substitute for that hardware check.

The existing 3.6.0 macOS requirements and signing/permission limitations still
apply. No new audio controls, native Metal renderer, lossless video path or
legacy macOS dependency support is included in this candidate.
